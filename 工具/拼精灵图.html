拼精灵图工具

把一个角色的若干单张 PNG 拼成一张图集（网格排布）+ 一份索引 JSON。全部在本机浏览器里完成，图片不上传。

第 1 步：选图 还没选图
第 2 步：排布设置
第 3 步：生成与下载
怎么放进角色包
  1. 把下载到的 图集.png 和 图集.json 放进 models/角色名/sheet/（两个文件放同一目录，文件名保持一致）。
  2. 在角色的 characters/角色名/character.js 里加 sheets 表，例如：
    sheets: { main: { image: "models/角色名/sheet/图集.png", index: "models/角色名/sheet/图集.json" } }
  3. 把 images 里对应的图改成帧引用，例如：
    normal: { sheet: "main", frame: "normal" }（frame 省略时默认取键名）。
  4. 跑一遍 node 工具/精灵图自检.mjs 角色名，PASS 就完工了。
