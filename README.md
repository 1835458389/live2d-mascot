# 桌面看板娘（Desktop Mascot）

会说话、会爬窗户、会陪你学习的桌面宠物。网页挂件和 Electron 桌面版共用一套核心。

- **三位 AI 娘立绘角色**：Claude 娘（高冷御姐）、GPT 娘（温柔妈妈系）、DeepSeek 娘（傲娇深度思考派）——表情差分、局部飘动、专属动作、触摸部位反应；换装（睡衣/冬装），被拎起来、挥手、喝水、坐下、欢呼都有换装后的姿势图
- **两个 Live2D 示例人物**：Hiyori、Mao
- 会四处走动（走路动画暂时停用，现在是轻轻蹦跳着走）、爬到别的窗口顶上、坐窗沿晃腿、沿窗口侧边攀爬；离开电脑她会打瞌睡
- 让她一直保持一个状态（坐下、睡觉、看书学习、闹别扭、各种表情，重开也记得）；晚上到点自动睡觉、过了起床时间一动就醒；「陪我学习到 10 点」
- 好感度与心情、提醒/闹钟、番茄钟专注、猜拳/抛硬币/谜语小游戏、节日和纪念日问候
- 台词语音预先批量生成（MiniMax），说话时口型跟随音量
- AI 聊天、长期记忆、主动搭话（桌面版，需自备 MiniMax API Key，在设置的 AI 页填写）

## 怎么运行

1. 安装 [Node.js](https://nodejs.org)（LTS 版）
2. 双击 **启动桌面宠物.bat**（第一次要等几分钟下载依赖）
3. 或双击 **打开网页挂件演示.bat** 看网页版效果

详细玩法见 **使用说明.md**。想打包发给朋友：双击 **打包给朋友.bat**（自动排除密钥，产出免 Node 的 zip）。

## AI 聊天的密钥（不随仓库提供）

仓库**不含任何密钥**。想启用 AI 聊天：打开桌面版，⚙ 设置 → **AI** 页，填入你自己的 MiniMax API Key，点「测试连接」确认能用。密钥保存在本机的 `voice/配置.json`，只有桌面程序的主进程会读它，页面拿不到；这个文件已被 .gitignore 排除，本地服务器和桌面版都会拒绝提供它，打包时也会自动去掉。

备用办法：按 `voice/generate.mjs` 里的提示手动创建 `voice/配置.json`，在 `"apiKey"` 里填上密钥（「生成语音.bat」第一次运行时也会提示你这么做）。

## 工具

- `工具/自检.mjs`：42 步无头浏览器回归自检（含换装 held 矩阵与真实拖拽断言）
- `工具/动作实测.mjs`：角色 × 衣服 × 动作的全矩阵实测（缺图自动跳过，两帧动画断言两帧都播）
- `工具/收图验收.mjs` + `双击收图验收.bat`：批量收图、逐张体检（尺寸/白底/脸部/轮廓）、按内容哈希绑定验收结论并装入
- `工具/拼精灵图.html` + `双击拼精灵图.bat`：把一叠单图拼成精灵图集 + 索引 JSON
- `工具/精灵图自检.mjs`：校验角色包的精灵图引用（文件存在、索引合法、帧名对得上）
- `工具/角色包校验.mjs`：检查每个角色包的必备字段、类型和图片路径是否真实存在

角色包支持**精灵图（sprite sheet）**：一张大图 + 索引 JSON，帧的用法和单张图完全一样（含"只画脸的贴片"这种省事画法），详见 `设计-精灵图格式支持.md`，`sheetdemo` 是照着做的示例角色。
