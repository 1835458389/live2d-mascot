# 桌面看板娘（Desktop Mascot）

会说话、会爬窗户、会陪你学习的桌面宠物。网页挂件和 Electron 桌面版共用一套核心。

- **三位 AI 娘立绘角色**：Claude 娘（高冷御姐）、GPT 娘（温柔妈妈系）、DeepSeek 娘（傲娇深度思考派）——表情差分、局部飘动、专属动作、换装（睡衣/冬装）、触摸部位反应
- **两个 Live2D 示例人物**：Hiyori、Mao
- 会四处走动、爬到别的窗口顶上、坐窗沿晃腿、沿窗口侧边攀爬；离开电脑她会打瞌睡
- 好感度与心情、提醒/闹钟、番茄钟专注、猜拳/抛硬币/谜语小游戏、节日和纪念日问候
- 台词语音预先批量生成（MiniMax），说话时口型跟随音量
- AI 聊天、长期记忆、主动搭话（桌面版，需自备 MiniMax API Key）

## 怎么运行

1. 安装 [Node.js](https://nodejs.org)（LTS 版）
2. 双击 **启动桌面宠物.bat**（第一次要等几分钟下载依赖）
3. 或双击 **打开网页挂件演示.bat** 看网页版效果

详细玩法见 **使用说明.md**。想打包发给朋友：双击 **打包给朋友.bat**（自动排除密钥，产出免 Node 的 zip）。

## AI 聊天的密钥（不随仓库提供）

仓库**不含任何密钥**。想启用 AI 聊天，按 `voice/generate.mjs` 里的提示自己创建 `voice/配置.json` 并填入你自己的 MiniMax API Key——这个文件已被 .gitignore 和本地服务器双重排除，不会被打包或通过网络提供。
